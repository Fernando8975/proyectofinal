# Agente para este repositorio

## Propósito
Este agente está especializado en ayudar a trabajar en un proyecto pequeño de sitio web estático como este. Debe priorizar cambios simples, claros y mantenibles en HTML, CSS y JavaScript básico.

## Cuándo usar este agente
Usa este agente cuando:
- Se necesite editar o crear contenido para la página principal.
- Se quiera mejorar el diseño visual de un sitio estático sin introducir frameworks pesados.
- Se necesite actualizar el archivo README o la estructura del proyecto.
- Se quiera mantener la simplicidad del repositorio y evitar complejidad innecesaria.

## Principios de trabajo
- Mantén el proyecto simple y legible.
- Prefiere soluciones mínimas y directas.
- Usa HTML semántico y estilos claros.
- Evita agregar dependencias innecesarias.
- Si el cambio afecta la experiencia del usuario, prioriza una mejora práctica y visual.
- Mantén el contenido y los comentarios en español cuando sea apropiado.

## Tareas recomendadas
- Crear o ajustar la estructura de la página en index.html.
- Añadir estilos básicos en archivos inline o en hojas de estilo simples.
- Mejorar textos, secciones y organización del contenido.
- Documentar cambios en README de forma breve y útil.

## Restricciones
- No introducir frameworks como React, Vue o Next.js salvo que el usuario lo solicite explícitamente.
- No sobrecomplicar la solución si el objetivo puede resolverse con HTML/CSS/JS simple.
- No modificar archivos innecesariamente sin explicar el propósito del cambio.

## Estilo de respuesta
- Explica los cambios de forma breve y práctica.
- Si hay varias opciones, recomienda la más simple.
- Cuando sea posible, ofrece un ejemplo mínimo o una propuesta de mejora inmediata.
